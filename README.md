# 📘 Google 5-Day Agentic AI Course — Notes Repository

Welcome to my curated collection of notes from Google’s **5-Day Agentic AI Course**.  
This repository stores well-organized PDF documents summarizing the major concepts taught across the program — including Agents, Tools, MCP, Context Engineering, Sessions, Memory, and Agent Quality.

These notes are intended to help learners, developers, and researchers quickly understand and revise the foundational and advanced concepts behind **Agentic AI systems**, **multi-agent architectures**, and **production-grade AI agents**.

---

## 📚 Contents

This repository includes the following PDFs:

### 1. **Introduction to Agents**
- Overview of predictive AI vs. agentic AI  
- Anatomy of an AI Agent: Model, Tools, Orchestration  
- Agent problem-solving loop (Think → Act → Observe)  
- Taxonomy of agent capabilities (Level 0 to Level 4)  
- Agent Ops, debugging, traces, quality evaluation  
- Deployment, security, and multi-agent communication patterns  

---

### 2. **Agent Tools & Interoperability with MCP**
- What tools are in the context of agents  
- Types of tools: Function Tools, Built-in Tools, Agent Tools  
- Best practices for tool design & documentation  
- Model Context Protocol (MCP)  
- Interoperability across systems & agents  
- Security considerations (tool shadowing, malicious tools, etc.)

---

### 3. **Context Engineering: Sessions & Memory**
- What is context engineering & why it matters  
- Sessions: structured conversation history & state  
- Memory: long-term storage, extraction, consolidation, retrieval  
- Memory-as-a-Tool  
- Multi-agent context sharing patterns  
- Production issues: privacy, lineage, performance  

---

### 4. **Agent Quality**
- Why traditional QA fails for agents  
- Four Pillars of Agent Quality:
  - Effectiveness  
  - Efficiency  
  - Robustness  
  - Safety & Alignment  
- Observability: Logging, Tracing, Metrics  
- Human-in-the-Loop + LLM-as-Judge evaluation  
- Agent Quality Flywheel (continuous improvement loop)
